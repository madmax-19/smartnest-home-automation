How SmartNest works

📱 Dashboard
HTML · JS · Render⇄☁️ Supabase
Database · Auth · Realtime⇄🔌 ESP32
Relays · Gate · Sensors

The dashboard and the ESP32 never talk to each other directly. Both read and write the same Supabase tables, so you can control your home from anywhere with an internet connection.

Hardware used

ESP32 Dev Module · DHT11 temperature & humidity sensor · 16x2 I2C LCD · 1.3" SH1106 OLED · L298N motor driver with DC gear motors · 2 limit switches · LED/relay outputs

Users & access

Admins control everything. Guests can only view. New sign-ups start as guests until you promote them. Use the device role for the ESP32 account.
